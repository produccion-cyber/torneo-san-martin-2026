# Torneo San Martín 2026

Plataforma oficial del Torneo de Fútbol 5 San Martín Lácteos S.A.S. (Edición 2026).

## Descripción

Aplicación React construida con TypeScript y Vite que centraliza toda la información de la competencia:
- **Inicio General**: Métricas globales, líderes de ambas ramas, próximos partidos, últimos resultados verificados y accesos directos.
- **Categorías (Masculino y Femenino)**: Resumen, calendario oficial por jornadas y fases eliminatorias (Play-In, Semifinales, Final), resultados, tabla oficial de posiciones con criterios de desempate, plantillas y nóminas oficiales de equipos con dorsales y roles, estadísticas avanzadas (Goleadores, Asistencias, Valla Menos Vencida, MVP, Disciplina con régimen de multas COP, Fair Play y Generales), y presentación audiovisual oficial.
- **Calendario General**: Programación completa y resultados con filtros interactivos por estado y categoría.
- **Recuerdos del Torneo**: Galería oficial de momentos y nóminas fotográficas de cada jornada, con filtros por rama y visor lightbox en alta resolución.
- **Manual Oficial del Torneo**: Reglamento íntegro de 10 capítulos que rige la competición ("Primero las personas, después el resultado").
- **Ficha Oficial del Partido**: Modal detallado con escudos, árbitro designado, escenario con enlace directo a Google Maps y observaciones oficiales.

## Ejecución Local

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar servidor de desarrollo en el puerto 3000:
   ```bash
   npm run dev
   ```

3. Construir para producción:
   ```bash
   npm run build
   ```
