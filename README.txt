TORNEO SAN MARTÍN 2026 — PRIMERA VERSIÓN WEB

Abrir index.html en un navegador moderno. Para evitar restricciones de archivos locales, se recomienda iniciar un servidor local en esta carpeta, por ejemplo:
  python -m http.server 8000
Luego abrir http://localhost:8000

Los datos de data.json fueron extraídos de:
- Control Torneo 5 Equipos - Hombres.xlsx
- Control Torneo 5 Equipos - Mujeres.xlsx

La web es una primera versión estática funcional. La siguiente fase puede conectar el sitio a Google Sheets o a una base de datos para actualización automática.
